# CipherLink

**在不可信的聊天软件里，自己掌握加密。**

CipherLink 是一款 Android 端到端加密工具：你和对方先互换公钥，之后互发的内容都用对方的公钥加密，只有对方的私钥能解开。
密文可以通过任何聊天软件、社交平台、邮件传递——平台和中间人看到的永远只是一串乱码。

> 没有账号，没有服务器，没有网络权限。所有加解密都在你的手机本机完成。

---

## 立意

我们每天用微信、QQ、Telegram、短信聊天，但这些平台的"安全"取决于平台本身：它们能看到内容，或者你只能选择相信它们不看。

CipherLink 的想法很简单：**不去替换聊天软件，而是在它们之上再加一层只属于你们两个人的加密。**

- 聊天软件继续负责"送达"，CipherLink 负责"保密"；
- 密钥只存在于双方手机里，不经过任何第三方；
- 不依赖任何服务器，所以没有可被关停、可被入侵、可被调取的中心；
- 代码开源，原理公开，可以审计，不需要"相信我们"。

它适合：需要在公共平台上传递敏感信息的个人、记者与调查者、小团队，以及想亲手了解"非对称加密聊天"是怎么运作的开发者与学习者。

## 工作方式

```
  A 的手机                          聊天软件 / 任何信道                       B 的手机
 ┌──────────┐   ① 互换公钥（可公开）   ┌────────────────┐                  ┌──────────┐
 │ A 的私钥 │ ──────────────────────▶ │  只能看到乱码  │ ◀─────────────── │ B 的私钥 │
 │ B 的公钥 │                         │ CL2M.xxxxxxxx  │                  │ A 的公钥 │
 └──────────┘   ② 用对方公钥加密 ───▶ └────────────────┘ ─── ③ 用自己私钥解密 └──────────┘
```

1. 各自在手机上生成一对密钥，私钥永远不离开本机。
2. 互相把**公钥**发给对方（公钥可以公开，通过任何渠道发送都安全）。
3. 发消息时用对方的公钥加密，复制密文，粘贴到聊天软件里发出去。
4. 对方复制密文，在 CipherLink 里用自己的私钥解密。

## 功能

### 加密通信
- **文字加密**：输入内容 → 一键加密并复制 → 到聊天软件粘贴发送。
- **附件加密**：图片、压缩包等任意文件（最大 10 MB）加密成 `.clink` 文件，当作"文件"通过聊天软件发送；对方用 CipherLink 打开即可。
- **二维码传递**：密文可以转成二维码，过长时自动拆成多张并拼成一张图；可保存、复制或分享，对方截图后直接识别解密。
- **身份校验**：每条消息带发送方公钥和签名，防篡改、防冒充；保存为联系人后按指纹锁定身份，陌生发送方会明确标出，可一键保存。

### 方便到"无感"
- **通知栏**：只使用一条通知，里面有加密发送框、解密框，解密结果也直接显示在这里，不用打开 App。
- **悬浮窗**：可拖动的悬浮球，在聊天软件上方直接加密和解密。
- **自动解密**：可选监听剪贴板和新保存的二维码图片；只有发给你的有效密文才会提示，其他内容一律忽略，同一条消息只提示一次，也不会提示过时内容。
- **一键入口**：在聊天里长按选中密文，菜单里的"CipherLink 解密"一步解密；把二维码图或 `.clink` 文件"分享"给 CipherLink 也能解密；任意 App 里分享文件或文字到"CipherLink 加密发送"即可加密。
- **收件箱**：解密后的消息和文件保存在本机，可复制、保存、打开、删除。

### 保护你自己
- **启动密码**：连续输错会逐步延长等待时间；可设置离开后自动锁定的时间。
- **隐私屏**（可选）：禁止截屏录屏，最近任务里隐藏预览。
- **通知隐私**：锁屏时不显示内容；也可以关闭通知中的内容预览。
- **本机加密存储**：私钥由 Android Keystore 保护，收件箱和附件落盘前再加密一次；不允许备份和设备迁移带走。
- 支持暗色模式。

## 安全设计

| 项目 | 做法 |
| --- | --- |
| 非对称加密 | RSA-3072，OAEP 填充（SHA-256） |
| 内容加密 | 每条消息随机生成 AES-256-GCM 密钥，再用对方公钥封装 |
| 防篡改/防冒充 | SHA256withRSA 对消息头、密文、发送方公钥签名 |
| 二维码分片 | 先整体加密签名，再分片；收齐并整包校验后才解密 |
| 私钥存储 | Android Keystore（AES-GCM）保护，不导出 |
| 随机性 | 系统 `SecureRandom` 为主；首次建钥时用户触摸与时间戳作为**额外**熵 |
| 网络 | 不申请网络权限，没有任何联网代码 |

### 请了解的边界

CipherLink 保护的是"密文在传递途中不被看到"，它不能保护：

- **你的手机本身**：被植入恶意软件、被他人拿到已解锁的手机，加密就没有意义。
- **第一次交换公钥时的冒充**：请通过电话或当面核对双方的"指纹"。
- **元数据**：谁在什么时候联系了谁，聊天平台仍然知道。
- **明文出现之后**：解密后的内容显示在屏幕上、剪贴板里，请留意周围和其他 App。
- **Android 的系统限制**：Android 10 以后后台 App 无法读取剪贴板内容，所以后台剪贴板监听在多数手机上不会自动生效。打开 CipherLink 时会自动检查，也可以点通知栏或悬浮窗里的"解密剪贴板"一步完成。

项目没有经过第三方安全审计，请不要把它当作应对强对手的唯一防线。欢迎审查代码、提 Issue。

## 快速开始

1. 在 Android Studio 打开本项目，等待 Gradle 同步，连接手机运行；或自行构建 APK。
2. 首次打开，触摸屏幕约 3 秒，生成你的密钥。
3. 进入"联系人"页，把你的公钥发给对方，并添加对方发来的公钥。
4. 回到"消息"页，选择收件人，输入内容，点"加密并复制文本"，去聊天软件粘贴发送。
5. 收到密文时，复制后点"粘贴并解密"。

## 构建环境

- Android Studio（最新稳定版），JDK 17
- Android Gradle Plugin 9.4.0 / Gradle 9.6.0
- minSdk 26，compileSdk / targetSdk 36
- 唯一依赖：[ZXing core](https://github.com/zxing/zxing)（二维码编码与识别）
- 纯原生 Android View 实现，不依赖 AndroidX / Material 库

## 项目结构

```
app/src/main/java/com/cipherlink/app/
├── crypto/     加密协议（密钥、封装、签名、附件信封）
├── core/       消息处理流水线、通知、剪贴板、图片与二维码工具
├── storage/    本地存储（身份、联系人、收件箱、附件加密）
├── qr/         二维码编码、分片与重组
├── service/    后台监听、悬浮窗
├── receiver/   通知栏输入、开机恢复
└── ui/         各页面与对话框
```
